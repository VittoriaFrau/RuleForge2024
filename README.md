Reccommended Unity version: 22.3.20f1


How to import Ruleforge within a project:
1. Make sure MRTK3 is installed https://learn.microsoft.com/en-us/windows/mixed-reality/mrtk-unity/mrtk3-overview/getting-started/setting-up/setup-new-project
	- Required dependencies: 
		- Platform Support → Mixed Reality OpenXR Plugin, MRTK3 → MRTK Input
		- MRTK3 → MRTK Input
		- MRTK3 → MRTK Core Definitions
		- MRTK3 → MRTK UX Core Scripts
		- MRTK3 → MRTK Spatial Manipulation
		- MRTK3 → MRTK UX Components
